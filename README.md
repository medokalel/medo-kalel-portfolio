## 🎯 Features

- **🌓 Dark & Light Mode** — Full theme toggle with CSS variables and localStorage persistence
- **📱 Fully Responsive** — Mobile-first design with custom breakpoints
- **🎨 Modern UI/UX** — Clean gradients, glassmorphism effects, and smooth transitions
- **📧 Contact Form** — Working email integration via EmailJS with validation
- **🖼 Project Showcase** — Interactive project cards with details
- **⭐ Testimonials Slider** — Auto-playing carousel using Swiper
- **📜 Journey Timeline** — Animated career/education timeline
- **🔝 Scroll to Top** — Smooth scroll functionality
- **🍔 Mobile Sidebar** — Responsive navigation with overlay
- **⚡ Fast Performance** — Vite-powered HMR and optimized builds
